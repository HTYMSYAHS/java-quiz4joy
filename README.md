# Java Syntax Recall Quiz

Active-recall practice tool for **Introduction to Programming** (Java).

Built from the course materials focusing on:
- Instantiable classes (data members, constructors + `this`, set/get/compute)
- Selection & validation
- Loops
- Strings & characters
- Arrays
- Basic syntax & Scanner

## Modes
- **Practice**: Instant feedback and explanation after each question. Good for learning.
- **Test**: No feedback until the end. Limited to ~15 questions. Shows score and which ones you missed.

## Topics (104 questions total)
- Basics & Scanner (20)
- Instantiable Classes (20)
- Selection & Validation (10)
- Loops (10)
- Strings & Chars (14)
- 1D Arrays (10)
- 2D Arrays (12)
- Mixed / Full Pattern (8)

Many variations so you can run repeated Practice then Test sessions without exhausting the bank.

## Host on GitHub Pages
1. Create a new public GitHub repository.
2. Upload all files in this folder (`index.html`, `styles.css`, `app.js`, `questions.js`, `README.md`).
3. Go to Settings → Pages → Source: Deploy from branch → main / root.
4. Your quiz will be live at `https://yourusername.github.io/repo-name/`.

## Practice tips
- Cover the answer and try to recall from memory first.
- Short daily sessions work better than long cramming.
- Focus extra on Instantiable Classes and the set → compute → get pattern.

Good luck with the repeat!
